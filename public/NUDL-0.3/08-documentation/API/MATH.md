# NUDL Math API

## Exact arithmetic
Integers, rational values, arbitrary-precision numeric profile, constants, powers, and roots.

## Symbolic mathematics
Simplification, expansion, factorization, solving, and substitution.

## Calculus
Limits, differentiation, integration, and series.

## Numerical mathematics
Root finding, numerical integration, optimization, interpolation, and ODE solvers.

## Linear algebra
Vectors, matrices, determinants, decompositions, linear systems, and tensors.

## Statistics
Mean, median, variance, distributions, regression, confidence intervals, and hypothesis tests.

Every function must distinguish exact results from numerical approximations and document assumptions and tolerances.
