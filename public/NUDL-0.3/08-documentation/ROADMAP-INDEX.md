# Noodle Roadmap Index

The master roadmap is ROADMAP.md.

Strategic sequence:
1. NUDL 0.3 foundation
2. complete language core
3. semantic model
4. typed Noodle IR
5. native runtime
6. Noodle-native self-hosting compiler
7. native CPU backends
8. SIMD and parallel execution
9. GPU and accelerator backends
10. standard library
11. interoperability
12. IDE and tooling
13. application and research corpus
14. performance and correctness research
15. security and reliability
16. Noodle 1.0
17. Noodle 2.x research

The critical milestone is Phase 5: a Noodle compiler that compiles its own Noodle compiler source and passes the self-hosting conformance suite.
