# Omni-to-NUDL Example Corpus

This directory translates the documented Omni concepts into original NUDL examples. These are NUDL examples inspired by the repository's Omni research, not copied Omni source code.

## Coverage

02 functions and control flow

Files marked proposed syntax describe the target language design until the NUDL compiler implements the corresponding feature.
