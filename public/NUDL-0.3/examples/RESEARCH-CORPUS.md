# Noodle Programming Research Corpus

The numbered examples progress from language fundamentals through execution, optimization, and research experiments.

01-05: types, functions, conditionals, loops, arrays
06-09: structures, modules, data, errors
10-14: mathematics, units, parallelism, classes, trees
15-20: plugins, FFI, data, state, generics, complete programs
21-27: evaluation order, compiler pipeline, numerical semantics, validation, parallelism, thesis experiments

For each program record:
1. Research question
2. Noodle source
3. Expected behavior
4. Lexical token stream
5. AST
6. Scope and name resolution
7. Static type information
8. Typed IR
9. Optimization opportunities
10. Target backend
11. Runtime behavior
12. Test results
13. Performance measurements
14. Comparison implementation
15. Limitations and conclusion

No performance, portability, safety, or correctness claim is established until reproducible evidence exists.
