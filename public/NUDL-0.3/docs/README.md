# Noodle IDE — GitHub Pages

Browser-based NUDL editor prototype.

## Features
- Compact source editor
- Project/file selector
- Compile/analyze control
- Target selector
- Diagnostics and output
- Downloadable .nudl source
- Responsive desktop/mobile layout

## Pages
Configure GitHub Pages to publish the repository's **docs** directory. The IDE is at `/ide/`.

The browser implementation is an analyzer/playground. It does not claim to perform native CPU, SIMD, GPU, Android, iOS, or desktop compilation yet; those require the Noodle compiler backend.
